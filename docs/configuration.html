Configuration Reference

Aastro uses a single declarative YAML configuration file.

info

Only YAML is supported. JSON and TOML are not supported to reduce complexity and avoid inconsistencies.

The configuration is organized into focused sections, each covered on its own page:

SectionCovers
Server & AdminThe data port, TLS/mTLS, certificate hot-reload, the admin port, health & readiness probes
ObservabilityEnabling metrics and tracing instrumentation
Routing & FlowsTrusted proxies, rate limiting, flow matching, aggregation, streaming
Upstreams & PolicyUpstream targets, upstream TLS, retries, circuit breaker, load balancing
Plugins & MiddlewaresRegistering plugins and middlewares on a flow

debug: false
