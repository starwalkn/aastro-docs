Command-Line Interface

Aastro ships as two binaries:

  • aastro - the gateway daemon. Starts the HTTP server, tests configuration, prints version information.
  • aastroctl - companion tool for developers and DevOps. Generates plugin scaffolding and (in future versions) communicates with a running daemon.

Both follow standard Unix conventions: short and long flags (-c / --config), grouped short flags (-tq is -t -q), -- as a positional argument terminator, and KEY=VALUE for long flag values - see Conventions for the details shared by both binaries.
